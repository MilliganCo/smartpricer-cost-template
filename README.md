# SmartPricer Cost Template Helper

Офлайн-подготовка нового XLSX с двумя колонками: артикул и себестоимость/закупочная цена. Данные соединяются по номеру строки, а названия выходных колонок берутся из образца шаблона. API, загрузки цен, база данных и реклама в программе не используются.

Результат — отдельный двухколоночный файл с заголовками в первой строке. Исходное оформление, инструкции, макросы и остальные листы шаблона в него не копируются. Прием такого файла актуальным SmartPricer не проверялся; перед ручной загрузкой нужно проверить схему и значения.

## Входные данные

| Файл | Где искать | Обязательные колонки |
|---|---|---|
| Себестоимость | первый подходящий лист, заголовки в строке 1 | `НОМЕР СТРОКИ`, `СЕБЕСТОИМОСТЬ` |
| Соответствие артикулов | первый лист, заголовки в строке 1 | `НОМЕР СТРОКИ` и колонка с `АРТИКУЛ` + `OZON` в названии |
| Образец SmartPricer | первый подходящий лист, заголовки в строке 6 | колонки с `АРТИКУЛ` и `ЗАКУП` в названии |

Для поиска названия нормализуются к верхнему регистру. Целочисленные номера строк могут быть числами или числовым текстом; дубли запрещены, чтобы избежать неоднозначного соответствия. Полностью пустые строки пропускаются. Соединение внутреннее: несовпавшие номера в результат не входят, пустые артикулы удаляются. Неизвестная себестоимость остается пустой, а не превращается в ноль.

Артикулы с ведущими нулями храните в Excel как **текст**. Числовое форматирование вида `000000` не восстанавливает потерянные исходные цифры. Если под ключевое слово подходит несколько колонок, текущий поиск выбирает первую — проверьте образец заранее.

## Запуск

Нужен Python 3.10+.

```powershell
python -m pip install -r requirements.txt
python sebes.py --ozon-prices costs.xlsx --articles articles.xlsx --template template.xlsx --out result.xlsx
```

Либо заполните свою копию `config.example.json` и передайте ее через `--config private.json`. Все четыре пути в примере изначально пусты. Относительные пути в конфигурации считаются от папки этого файла, аргументы CLI имеют приоритет. Автоматического поиска личного конфига или открытия старых файлов по умолчанию нет.

Существующий результат проверяется перед записью; разрешение на замену — `--overwrite`. Заменять любой из входных файлов запрещено даже с этим флагом. Это проверка последовательного запуска, а не блокировка от параллельных процессов. Считыватели Excel закрываются после использования.

## Синтетические проверки

```powershell
python -B -m unittest discover -s tests -v
```

Тесты создают вымышленные книги только во временной папке внутри `work/`: проверяют текстовые артикулы, числовые себестоимости, пустые значения, дубли, сохранность входов и явную конфигурацию. Реальные цены, товарные книги и внешние сервисы для этих проверок не нужны. Вычисление формул Excel, пересчет валют, формат полного upload-шаблона и текущая совместимость сервиса не подтверждены.
